This page lists all Pokémon Generation IV game versions and accessories for all consoles. It also explains what game versions are compatible.

#### DS Console

- DS and DS Lite consoles are same world-wide and can play any game versions. Those consoles can play DS and GBA games, and transfer Pokémon from GBA to DS.
- DSi consoles exist in multiple versions based on region. They can play DS games from any language and any region. They can't play GBA games. They can only play DSi games from the region of the DSi console. There are no DSi Pokémon games.

#### DS Game Versions

Pokémon Diamond, Pearl, Platinum, HeartGold, SoulSilver games each have 7 versions based on language.

- English (The US, Canada, UK, Australia retail boxes are different, but the GBA cartridge content is the same.)
- Japanese
- French
- Italian
- Spanish
- German
- Korean

##### Main Core Series

Pokémon Diamond, Pearl, Platinum, HeartGold, SoulSilver games each have 8 versions based on language and region.

- **Japan:** Japanese language
- **The Americas and Asia:** English language
- **Europe and Oceania:** English, French, German, Italian or Spanish (Unchangeable)
- **Korea:** Korean language

A notable difference between Americas English version and Europe English version is that the Americas version has access to the Game Corner, while the Europe one doesn't.

##### Pokémon Ranger Series

Pokémon Ranger, Pokémon Ranger: Shadows of Almia, Pokémon Ranger: Guardian Signs games each have 3 versions based on region.

- **Japan:** Japanese language
- **The Americas and Asia:** English language
- **Europe and Oceania:** English, French, German, Italian or Spanish language (Changeable)

#### DS Accessories

- **PokéWalker:** There is only 1 version of the PokéWalker which can connect with HeartGold or SoulSilver games from any language.

#### Wii Console

The Wii has 5 officially released versions.

- **NTSC-J (Japan):** Japanese language (unchangeable)
- **NTSC-J (Hong-Kong, Taiwan):** Traditional Chinese language (unchangeable)

  - No Pokémon games were released for the Chinese WII.
- **NTSC-U (The Americas, Middle East, Southeast Asia):** TODO
- **PAL (Europe, Oceania, Indian, African): TODO**
- **NTSC-K (South Korea):** Korean language (unchangeable)

  - No Pokémon games were released for the Korean WII.

#### Accessories

- **Wii Controllers:** They are the same world-wide and can be used on any console version.
- **Memory Card:** They are the same world-wide and can be used on any console version. The same Memory Card can only contain information of a single region at once. Ex: It can't contain both a NTSC-J and NTSC-U saves at once.

#### Game Versions

A Wii game is specific to a region and can only be played on a Wii of that region.

My Pokémon Ranch (without update) exists in 3 versions. Is is discontinued since Wii Shop Channel's shutdown on January 31, 2019. It can interact with Pokémon Diamond and Pearl of the same language.

It can be used to obtain Phione and Mew.

- **NTSC-J (Japan):** Japanese language
- **NTSC-U (The Americas and Asia):** English language
- **PAL (Europe and Oceania):** Uses the Wii language (English, German, French, Spanish, Italian).

My Pokémon Ranch (updated) exists in 1 version: Japanese. Is is discontinued since Wii Shop Channel's shutdown on January 31, 2019. It can interact with Japanese Diamond, Pearl and Platinum.

- **NTSC-J (Japan):** Japanese language

Pokémon Battle Revolution exists in 4 versions. They can interact with DS games of the same language. It is notable for providing Soul Dew and rare berries such as Starf Berry. However, it offers no exclusive content.

- **NTSC-J (Japan):** Japanese language.
- **NTSC-U (The Americas and Asia):** English language.
- **PAL (Europe and Oceania):** Uses the Wii language (English, German, French, Spanish, Italian).
- **NTSC-J (Taiwan):** Chinese language. TODO: It is unknown if it can interact with DS games.

#### Wii-Game Cube Interactions

All Wii (except Chinese and Korean) can play Game Cube games of the same region. However, Game Cube Pokémon games played on the Wii can't interact with other games because the Wii is not compatible with the Game Cube to GBA Link Cable.
