This page lists all Pokémon Generation I game versions and accessories for all consoles. It also explains what game versions are compatible.

#### GB Console

- **Game Boy consoles:** They are same world-wide and can play any game versions.

#### GB Accessories

- **Game link cables:** They are the same world-wide and can be used on any game versions and consoles.

#### GB Game Versions

GB game versions depend on language.

The same game was sold in multiple regions. For example, the US, Canada, UK, Australia retail boxes are different, but the GB English cartridge content is the same.

- **Pokémon Green (Japan)**: Japanese.
- **Pokémon Red (Japan)**: Japanese.
- **Pokémon Blue (Japan)**: Japanese.
- **Pokémon Red (International)**: English, Spanish, French, Italian, German.

  - The game is slightly different than Pokémon Red (Japan).
- **Pokémon Blue (International)**: English, Spanish, French, Italian, German.

  - The game is slightly different than Pokémon Red (Japan).
- **Pokémon Yellow (International)**: Japanese, English, Spanish, French, Italian, German.

  - The game is slightly different than Pokémon Blue (Japan).

#### GB-GB Interactions

- **Trade & Link Battle:**

  - The games are split in 2 compatibility groups: Japanese and English/French/Italian/Spanish/German.
  - Games can only trade with games of the same group.

#### N64 Console

N64 has 4 versions based on region.

- **NTSC-J:** Japan
- **NTSC-U:** The Americas and Asia
- **PAL:** Europe and Oceania
- **NTSC-C:** China

  - The N64 console was rebranded as iQue in China. No N64 Pokémon games exist for that console version.

In South Korea, the N64 console was rebranded as Hyundai Comboy 64. It has the same features and compatibility as the NTSC-J sold in Japan.

#### N64 Accessories

- **Transfer Pak for Nintendo 64:** They are the same world-wide and can be used on any game versions and consoles.

#### N64 Game Versions

A N64 game is specific to a region and can only be played on a N64 of that region. N64 Pokémon games only has 1 specific unchangeable language.

##### Pokémon Stadium (Japan)

Only 1 version exists.

- NTSC-J Japanese

##### Pokémon Stadium 1

8 versions exist. It is known as Pokémon Stadium 2 in Japan.

- NTSC-J Japanese
- NTSC-J English
- NTSC-U English
- PAL English
- PAL German
- PAL French
- PAL Spanish
- PAL Italian

#### N64-GB Interactions

- GB games (Pokémon Red, Blue, Yellow, Green) can connect to Pokémon Stadium (Japan) and Pokémon Stadium 1 on N64 using the Transfer Pak.
- N64 games are split in 2 compatibility groups: NTSC-J and NTSC-U/PAL.
