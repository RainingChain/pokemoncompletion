This page lists all Pokémon Generation II game versions and accessories for all consoles. It also explains what game versions are compatible.

#### GB Console & Games

Check [Pokémon Generation I Version Compatibility](./GenI) page.

#### GBC Console

- **Game Boy Color console:** They are same world-wide and can play any game versions.
- **Game Boy Advance console:** They are same world-wide and can play any game versions (and trade). However, the Game Boy Advance doesn't support infrared features such as Mystery Gift. To trade with Generation 2 games, a GBC game link cable must be used (GBA game link cable will not work).

#### GBC Accessories

- **Game link cables:** They are the same world-wide and can be used on any game versions and consoles.
- **Mobile Game Boy Adapter:** Only works on Japanese Pokémon Crystal and NTSC-J (Japan) Pokémon Stadium 2 games.

#### GBC Game Versions

#### GBC-GBC Interactions

- **Trade, Link Battle, and Mystery Gift:**

  - The games are split in 3 compatibility groups: Japanese, Korean and English/French/Italian/Spanish/German.
  - Games can only trade, battle and perform Mystery Gift with games of the same group.

#### GB-GBC Interactions

Game Boy games (Red, Blue, Green, Yellow) can trade with GBC games (Gold, Silver, Crystal) with restrictions.

The mechanism for trading between Generation 1 and Generation 2 games is called Time Capsule.

- **Trade:**

  - The games are split in 3 compatibility groups: Japanese, Korean and English/French/Italian/Spanish/German.
  - Games can only trade with games of the same group.

- **Link Battle:** Not possible using two handlheld consoles. Battle is possible by connecting a Generation 1 and a Generation 2 games with Transfer Paks and Pokémon Stadium 2 on the N64 (See N64 Compatibility section).

#### N64 Console

N64 has 4 versions based on region.

- **NTSC-J:** Japan
- **NTSC-U:** The Americas and Asia
- **PAL:** Europe and Oceania
- **NTSC-C:** China

  - The N64 console was rebranded as iQue in China. No N64 Pokémon games exist for that console version.

In South Korea, the N64 console was rebranded as Hyundai Comboy 64. It has the same features and compatibility as the NTSC-J sold in Japan.

#### N64 Accessories

- **Transfer Pak for Nintendo 64:** They are the same world-wide and can be used on any game versions and consoles.

#### N64 Game Versions

A N64 game is specific to a region and can only be played on a N64 of that region. N64 Pokémon games only has 1 specific unchangeable language.

##### Pokémon Stadium 2

8 versions exist. It is known as Gold and Silver in Japan.

- NTSC-J Japanese
- NTSC-J English
- NTSC-U English
- PAL English
- PAL German
- PAL French
- PAL Spanish
- PAL Italian

#### N64-GBC Interactions

- GB games (Pokémon Red, Blue, Yellow, Green) and GBC games (Gold, Siler, Crystal) can connect to Pokémon Stadium 2 on N64 using the Transfer Pak.
- GBC games (Gold, Siler, Crystal) can't connect to Pokémon Stadium 1.
- Pokémon Stadium 2 games are split in 2 compatibility groups: NTSC-J and NTSC-U/PAL.
