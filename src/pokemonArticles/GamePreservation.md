## Pokémon Game Preservation

Gist: The list of Pokémon games, with their preservation status. Only games requiring a server are listed.

### Lost Games

Those games could only be played online, and their servers were shutdown permanently. It is now near impossible to preserve them.

- Pokémon Dream World. Discontinued on January 14, 2014.
- Pokémon Trading Card Game Online (PC). Discontinued on June 5, 2023.
- Pokémate (Mobile). Discontinued on January 31, 2008.
- Pokémon Duel (Mobile). Discontinued on October 31, 2019
- Pokémon Medallion Battle (Facebook). Discontinued on February 29, 2024.
- Pokémon Tower Battle. Discontinued in 2020?

### Games at Risk of Being Lost

Those games can only be played online. Once their server will shutdown, they will be lost forever.

- Pokémon Café ReMix
- Pokémon Sleep
- Pokémon Smile
- Pokémon GO (Mobile)
- Pokémon Trading Card Game Live (PC)
- Pokémon Trading Card Game Pocket (Mobile)
- Pokémon UNITE

### Preserved Games

Those games technically require a server at some point to be played, but there is a way to play them offline.

#### Pokémon Shuffle (3DS)

##### Online-only features:

- Access to Special stages (Competitive stage, Daily Pokémon, Escalation battle, Great Challenge, High-Speed Challenge, One Chance a Day!, Pokémon Safari, Resource events, Special Challenge, UB Challenge).
- Number of catchable Pokémon: offline 584, online 975.
- Number of obtainable Mega Stone Pokémon: offline 34, online 48.
- Maximum Trainer Rank: offline 22, online 30.
- Number of completable Mission cards: offline 18, online 19.

##### Preservation Status: <span class="preserved">Preserved</span>

A [mod](/completion/shuffle/dlc) for the game file (.cia) has been created that adds access to all the Special stages.

#### Pokémon Magikarp Jump (Mobile)

##### Online-only features:

- Starting a new game.

##### Preservation Status: <span class="preserved">Preserved</span>

A save data file has been conserved, right after starting a new game after connecting to the server. Contact RainingChain on [Discord](https://discord.com/invite/tMXrJzjWmg) for more info.
